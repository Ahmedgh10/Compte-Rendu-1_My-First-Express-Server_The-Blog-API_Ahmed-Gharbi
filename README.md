# MERN Session 4 - JWT, bcrypt, RBAC

1. `npm install`
2. Copy `.env.example` to `.env`, set your Atlas URI and JWT_SECRET.
3. `npm run dev`
4. Import `postman/MERN_S4.postman_collection.json`.
5. Public registration always creates role "user". To get an admin for the 403/200 tests:
   `npm run make-admin -- omar@polytechnique.tn`
